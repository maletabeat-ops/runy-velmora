# Руны Вельмора

Пиксельная RPG в браузере: три класса (маг, воин, следопыт), пять земель, четыре босса, предметы пяти редкостей, задания и сохранение.

Играть: https://maletabeat-ops.github.io/runy-velmora/

На телефоне открой ссылку и выбери «Добавить на главный экран» — игра запустится как приложение, на весь экран.
