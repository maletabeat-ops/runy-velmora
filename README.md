# Руны Вельмора

Пиксельная RPG в браузере: три класса (маг, воин, следопыт), пять рас (человек, эльф, гном, лисолюд, орк), семь земель, шесть боссов, предметы пяти редкостей, задания и сохранение.

**Играть:** https://maletabeat-ops.github.io/runy-velmora/

На телефоне открой ссылку и выбери «Добавить на главный экран», на компьютере в Chrome нажми значок установки в адресной строке. Игра запустится как приложение, на весь экран.
