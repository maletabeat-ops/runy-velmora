# Острова Шторма

Пиксельная RPG в браузере. Над архипелагом бушует Вечный шторм: собери пять жемчужин бури, подними Затонувший храм и победи Морвен, Глаз Шторма.

**Играть:** https://maletabeat-ops.github.io/runy-velmora/

- Три класса: штормовой маг, абордажник, следопыт
- Пять рас: человек, рыболюд, птицелюд, черепаха-отшельник, лисолюд-мореход
- Архипелаг из восьми островов и открытое море, своя лодка с улучшениями
- Три подземелья с этажами, ловушками и загадками
- Таланты, крафт, спутники, смена дня и ночи, задания с выбором, «Новая игра+»

На телефоне открой ссылку и выбери «Добавить на главный экран», на компьютере в Chrome нажми значок установки в адресной строке.
